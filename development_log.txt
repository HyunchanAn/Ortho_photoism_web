# 개발 진행 로그 (Development Log)
날짜: 2025-12-27

## 개발 완료 사항 (Completed)

### 1. 템플릿 엔진 및 코어 (Template Engine & Core)
- **JSON 기반 템플릿 시스템 구축**: `template.ts`, `data/orthodontic_basic.ts`를 통해 확장 가능한 템플릿 구조 설계.
- **교정용 3x3 기본 템플릿**: Rest, Smile, Intraoral 뷰를 포함한 표준 격자 구현.
- **Fabric.js v6 통합**: 최신 캔버스 라이브러리를 도입하여 고성능 이미지 렌더링 환경 구축.

### 2. 스마트 업로더 및 자동 배치 (Smart Uploader)
- **Drag & Drop 지원**: 파일 탐색기에서 이미지를 드래그하여 즉시 로드.
- **파일명 기반 자동 할당 (Auto Allocation)**: `front`, `smile` 등 키워드를 분석하여 템플릿의 지정된 슬롯에 자동 배치.
- **자동 전처 (Pre-actions)**: 템플릿 설정에 따라 이미지 로드 시 자동 회전(Rotation) 및 뒤집기(Flip) 적용 (예: 교합면 사진).

### 3. 편집 및 조작 도구 (Manipulation Tools)
- **캔버스 툴바 (Canvas Toolbar)**: 각 사진 슬롯 위에 마우스 오버 시 `Reset Position`, `Clear` 버튼 제공.
- **사이드바 조정 패널**:
  - **다중 선택 (Multi-select)**: 체크박스를 통해 여러 사진 동시 선택 가능.
  - **필터 및 조절**: 밝기(Brightness), 대비(Contrast) 슬라이더 및 `Normalize`(자동 보정), `Grayscale` 원클릭 필터 구현.

### 4. 가이드라인 및 속성 편집 (Guides & Properties)
- **고급 가이드라인 (Advanced Guidelines)**: 화면 전체를 가로지르는 전역 가이드라인(Global Red Crosshair) 드래그 기능 구현.
- **런타임 속성 편집기**: 캔버스 우클릭 시 모달을 통해 제목, 키워드, 저장 파일명 규칙 실시간 수정 기능.

### 5. 내보내기 및 저장 (Export Suite)
- **미리보기 및 저장 모달**: `Export / Save` 버튼을 통해 통합 내보내기 UI 제공.
- **스마트 리네이머 (Renamer)**: `[<Savename>]_<Index>` 등의 태그 패턴을 사용하여 출력 파일명 일괄 변경 미리보기.
- **일괄 저장 (ZIP)**: 모든 캔버스를 고해상도 JPG로 변환하여 ZIP 파일로 압축 다운로드.
- **PDF 보고서 출력**: A4 레이아웃에 맞춘 PDF 리포트 생성 기능.
- **FileSaver.js 도입**: 브라우저별 다운로드 호환성 문제 및 파일명 강제 지정 문제 해결 (UUID 저장 이슈 해결).

### 6. 레이아웃 및 UX 개선 (Layout & UX Updates)
- **복합 레이아웃 (Composite Layout)**:
    - 상단(Extraoral): 3:4 비율 사진 가로 배열 (Rest, 45, 90, Smile).
    - 하단(Intraoral): 4:3 비율 사진 십자(Cross) 배열.
    - 전체 캔버스 비율 12:13 최적화.
- **수동 미러링 (Manual Mirror)**: 자동 뒤집기 기능을 제거하고 툴바에 '좌우 반전' 버튼 추가.
- **회전 슬라이더 (Rotation)**: 각 슬롯 툴바에 -180도 ~ +180도 회전 슬라이더 추가 (블록 중심 회전).

## 향후 계획 (Future Roadmap)

### 1단계: 기능 고도화
- [ ] **파일 정렬 기반 할당 (File Order Allocation)**: 파일명 매칭 실패 시, 파일 리스트 순서대로 빈 슬롯을 채우는 로직 보완.
- [ ] **정밀 확대/축소 로직**: 템플릿의 `magnification` 속성을 캔버스 초기 스케일에 반영하는 로직 정교화.
- [ ] **필터 추가**: `Denoise`(노이즈 제거), `Sharpen` 등 고급 필터 추가 (WebGL 쉐이더 검토 필요).

### 2단계: 사용성 개선
- [ ] **로컬 가이드라인**: 각 캔버스 내부에서만 작동하는 개별 격자/십자선 추가.
- [ ] **파일 시스템 API 도입**: 브라우저 보안 제약 없이 원본 폴더에 직접 '덮어쓰기' 또는 '새 폴더 저장'을 위한 File System Access API 연구.

### 3단계: 템플릿 확장
- [ ] **추가 템플릿 제작**: 5-photo, 8-photo 등 다양한 교정/치과용 템플릿 데이터셋 추가.
- [ ] **커스텀 템플릿 에디터**: 사용자가 직접 grid를 나누고 속성을 정의할 수 있는 GUI 에디터 개발.
